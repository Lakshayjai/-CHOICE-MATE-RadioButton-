🔘 ChoiceMate (RadioButton App)
Overview

This app demonstrates the use of RadioButtons to select one option from multiple choices.

Features
Multiple options using RadioButtons
Single selection logic
Displays selected option
Technologies Used
Java
XML
Android UI Components
Project Structure
RadioActivity.java → Handles selection logic
activity_radio.xml → Layout with RadioButtons
How It Works
User selects one option
Clicks button
App displays selected choice
Future Improvements
Add more options
Add UI styling
Store user selection
